# 開発ログ

このセクションでは、KestreLynxがどのように発展しているかを記録します。
取り組んでいる課題、試した方法、実装中に分かったこと、技術判断について記載します。

開発ログは作業中の内容を扱います。
現在利用できる機能の導入・運用方法は[ドキュメント](../documentation/index.md)を参照してください。
