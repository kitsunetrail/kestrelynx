## 用語 {#terms}

ドキュメントで使う用語の意味をまとめます。

### 全体で使う用語 {#common-terms}

複数の章で使う共通の用語を示します。

| 用語 | 意味 |
| --- | --- |
| 所見 | 配布元が対象リリースのサポート範囲外として扱うEOL（サポート終了）の脆弱性も含む、スキャンで検出した脆弱性 |
| 稼働イメージ | 稼働中のコンテナが使っているイメージ |
| ベースイメージ | Dockerfileの`FROM`で指定するイメージ |
| 修正版 | 脆弱性情報が「この版で直る」と報告している版 |
| 系列 | 版のまとまり（イメージのタグではmajor・minor・接頭辞・接尾辞が同じ版、言語ランタイムではNode.js 22やPython 3.13など） |
| サイクル | 定期的に実行するスキャンから通知までの1回分 |

### 修正計画と修正PRで使う用語 {#remediation-terms}

修正計画と修正PRの設定や処理、結果を読むための用語を示します。

| 用語 | 意味 |
| --- | --- |
| 配布イメージ | レジストリから取得してそのまま動かす既製イメージ |
| 固定タグ | `1.27.0`のように完全な版を指定するタグ |
| 浮動タグ | `latest`や`22-alpine`のように、指す内容が変わるタグ |
| コミットごとのタグ | `sha-5cf2d7b`のように、コミットのハッシュを名前にしたタグ |
| 対応付け | 稼働中のコンテナとGitHubリポジトリのファイルを結び付ける設定で、`remediation.mappings`の1項目 |
| ワークロードキー | 対応付けの`workload`で、対象のComposeサービス、Dockerコンテナ、Kubernetesのコンテナを識別する値 |
| 稼働版 | 稼働イメージで検出した版 |
| 更新目標 | 更新先を選ぶときの下限の版 |
| 採用版 | 更新後の依存ファイルで確認した版 |
| 手動対応 | KestreLynxが自動では更新せず、利用者に判断を任せる扱い（値は`manual`、Slackでは「要判断」） |
| 保留 | 上限や待機などのために、後のサイクルへ回す扱い（値は`deferred`、Slackでは「保留」） |
| 作業用コンテナ（作業用Pod） | パッケージマネージャーを実行するためにKestreLynxが作る使い捨てのコンテナ（Kubernetesでは作業用Pod） |
| 実行環境の一覧 | 言語パッケージの更新に使うNode.js・Python・Go・Gradle・Rustの系列ごとの実行版、digestで固定した公式イメージ、サポート終了日をまとめた一覧 |

KestreLynxは現在も開発中です。
特記がない限り、このドキュメントは最新のコンテナイメージと`main`ブランチの内容を説明しています。

バグ、機能要望、ドキュメントの修正は[GitHubリポジトリ](https://github.com/kitsunetrail/kestrelynx/issues)へIssueを作成してください。
