# Documentation

This section covers installing, configuring, and operating StackWatch.

## About StackWatch

- [Setup instructions](getting-started.md) — install StackWatch with Docker
  Compose or `docker run`.
- [Configuration](configuration.md) — configure the schedule, notification
  destinations, state management, and vulnerability prioritization.
- [How StackWatch works](how-it-works.md) — learn about scanning,
  prioritization, change detection, and notification processing.

StackWatch is under active development. Unless otherwise noted, this
documentation describes the latest container image and the current `main`
branch.

For bugs, feature requests, and documentation corrections, open an issue in the
[GitHub repository](https://github.com/kitsunetrail/stackwatch/issues).
